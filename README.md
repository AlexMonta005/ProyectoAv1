# Sistema de información - Estructura de Datos y Algoritmos II

Primera etapa: portada e índice interactivos en Java Swing.

## Requisitos
- JDK 17 o superior.
- Visual Studio Code.
- Extensiones recomendadas en VS Code: **Extension Pack for Java**.

## Ejecutar
1. Descomprime el proyecto.
2. Abre la carpeta `SistemaEDA2` en Visual Studio Code.
3. Abre `src/App.java`.
4. Pulsa **Run** sobre el método `main`, o ejecuta desde la terminal:

   ```bash
   javac -encoding UTF-8 -d out src/App.java
   java -cp out App
   ```

## Personalizar los logotipos
En la portada hay dos espacios reservados para los logotipos. En esta primera etapa son marcadores visuales; en el siguiente paso podemos reemplazarlos por los archivos PNG/JPG oficiales y ajustar su tamaño.
